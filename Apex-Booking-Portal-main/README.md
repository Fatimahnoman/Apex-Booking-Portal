# 📅 APEX RESERVE — Luxury Concierge & Interactive Booking Engine

> An ultra-premium, multi-step appointment scheduling platform engineered for executive consulting, high-end agency services, and enterprise workflows.

---

## 🌟 Overview

**APEX RESERVE** is an end-to-end booking and concierge scheduling engine built to streamline client onboarding, automate calendar slot management, and optimize high-ticket service conversions. Designed with dynamic obsidian glassmorphic aesthetics and sub-second performance, it features a 4-step booking wizard, live time-slot reservation, timezone auto-detection, and automated digital receipt/invoice generation.

## ✨ Key Features

* 💎 **Emerald & Obsidian Aesthetics:** Dark-mode glassmorphism (#060D0B) with electric mint highlights, glowing border strokes, and smooth motion dynamics.
* 🧙‍♂️ **4-Step Interactive Booking Wizard:** 
  1. **Service Selection:** Choose consultation tier, Specialist avatar, duration, and transparent pricing.
  2. **Dynamic Slot Picker:** Interactive calendar grid with live timezone synchronization and real-time slot locks.
  3. **Client Onboarding:** Clean form validation for user details, project scope, and multi-channel payment preference.
  4. **Automated Receipts:** Instant confirmation screen with dynamic unique Booking ID, calendar sync triggers, and printable PDF invoice view.
* 🔄 **Dual-Mode Architecture:** Integrated provider/client view toggle to preview backend calendar synchronization in real time.
* ⚡ **Sub-Second UX:** Micro-interactions, animated success celebrations, and interactive state feedback.

## 🚀 Getting Started (Local Setup)

To run this project locally on your machine:

```bash

git clone [https://github.com/Fatimahnoman/apex-booking-portal.git](https://github.com/Fatimahnoman/apex-booking-portal.git)

# 2. Navigate into the project directory
cd apex-booking-portal

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
